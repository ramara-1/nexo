# Nexo

Não mostre apenas quem você é. Mostre o que você está se tornando.

Rede para ideias, evolução, ajuda e conquistas — sem corrida por seguidores.

## Como rodar

```bash
npm install
npx prisma migrate dev
npx prisma db seed
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

Contas de demonstração (senha `nexo123`): `marina@nexo.social`, `leo@nexo.social`, `ana@nexo.social`.
